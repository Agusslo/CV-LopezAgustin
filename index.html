Hollownest Cinema

Sistema completo de venta de entradas para un cine, construido a partir de requisitos de un cliente que fueron cambiando durante el cuatrimestre.

  • Supabase + PostgreSQL con Row Level Security, login con email y Google
  • Roles cliente, empleado y admin con guards de rutas
  • Butacas en tiempo real con Supabase Realtime
  • Entradas en PDF con QR y validación escaneando con la cámara
  • Candy bar, cupones, combos, puntos de fidelización y cancelación con crédito
  • Panel admin con reportes, gráficos y log de actividad · PWA instalable
