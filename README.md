# CV / Portfolio Web — Agustín Nicolás López

Portfolio web personal desarrollado con HTML, CSS y JavaScript. Presenta perfil profesional, habilidades técnicas, experiencia laboral, educación, proyectos destacados y medios de contacto.

## Stack
- HTML
- CSS
- JavaScript

## Funcionalidades
- Diseño responsive
- Tema claro / oscuro con persistencia en localStorage
- Animaciones de entrada con IntersectionObserver
- Botón de descarga del CV en PDF
- Enlaces directos a GitHub, LinkedIn, WhatsApp y email
